# 교실 랜덤 학생 뽑기 (Classroom Random Selector) 🎯
> **제작: 오인석**  
> 공정하고 신나는 우리 반 무작위 추첨 웹 애플리케이션

---

## 🌟 주요 기능

1. **왼쪽: 학생 명단 관리**
   - **간편한 일괄 입력**: 줄바꿈(엔터)이나 쉼표(`,`)로 학생 이름을 한 번에 붙여넣기 할 수 있습니다.
   - **실시간 남은 명단 칩**: 대기 중인 학생 명단이 깔끔한 칩 형태로 표시되며, 실시간 잔여 인원이 자동 계산됩니다.
   - **개별 제외 기능**: 결석자나 이미 발표한 학생을 클릭 한 번으로 대기 명단에서 제외할 수 있습니다.
   - **자동 저장**: 입력한 학생 명단은 브라우저 로컬 저장소(`localStorage`)에 저장되므로 창을 닫거나 새로고침해도 그대로 유지됩니다.
   - **예시 명단(20명) 원클릭 로드**: 테스트용 명단을 빠르게 채워볼 수 있습니다.

2. **오른쪽: 대형 랜덤 뽑기 무대**
   - **교실 특화 시인성**: 교실 맨 뒤에서도 선명하게 보이는 대형 디스플레이와 깔끔한 서체.
   - **긴장감 넘치는 롤링 애니메이션**: 점진적으로 감속하는 슬롯머신 스타일 애니메이션.
   - **자체 효과음 (Web Audio API)**: 롤링 틱톡 비프음 + 당첨 축하 팡파레 (외부 mp3 파일 없이 100% 자체 합성 음향).
   - **축하 폭죽(Confetti) 효과**: 당첨 시 화면 가득 터지는 알록달록 색종이 파티클.
   - **조작 단축키 지원**: 마우스 클릭뿐만 아니라 `Space` 바를 눌러 즉시 뽑기를 실행할 수 있습니다.
   - **빠른 뽑기 모드**: 수업 시간이 촉박할 때 애니메이션 시간을 단축할 수 있는 토글 옵션 제공.

3. **하단: 뽑힌 순서 기록 & 명단 자동 제외**
   - **뽑힌 학생 자동 제거**: 뽑힌 학생은 왼쪽 남은 명단에서 즉시 사라져 **중복 추첨이 방지**됩니다.
   - **순서별 결과 누적**: 1순위(금메달), 2순위(은메달), 3순위(동메달) 등 순차적으로 카드가 누적됩니다.
   - **결과 클립보드 복사**: 클릭 한 번으로 뽑힌 순서(`1순위: 김민수`, `2순위: 이영희` ...)를 복사하여 메신저, 엑셀, 학급 일지에 바로 붙여넣기할 수 있습니다.
   - **명단 복원 및 다시 뽑기**: 기록을 초기화하고 원래 입력했던 전체 학생 명단을 한 번에 복원할 수 있습니다.
   - **완전 초기화**: 상단 헤더의 `[🔄 완전 초기화]` 버튼으로 등록된 명단, 남은 명단, 뽑힌 기록, 로컬 저장소를 모두 비우고 처음 상태로 되돌립니다.

---

## 🚀 실행 방법

별도의 설치 과정이나 웹 서버 구동 없이 **인터넷 연결이 없는 오프라인 환경에서도 즉시 실행**됩니다.

1. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등의 웹 브라우저에서 엽니다.
2. 상단의 **[⛶ 전체화면]** 버튼 또는 키보드 `F11`을 누르면 전자칠판/프로젝터 전용 모드로 전환됩니다.
3. 왼쪽에서 이름을 입력하거나 **[💡 예시 명단]**을 누른 후 **[✅ 명단 적용하기]**를 클릭합니다.
4. 오른쪽 **[🎲 랜덤 뽑기!]** 버튼 또는 키보드 `Space`를 눌러 추첨을 시작합니다!
